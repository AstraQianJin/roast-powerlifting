## 一、评分表（6 类 × 4 项，A/B 分开）

① 关标题后一眼认出是哪类器械（1–5）  
② 销位方向是否可读；plate / dumbbell / bw / special / barbell 改判“结构是否符合真机形态”  
③ 320 / 360 / 390 / 412 四宽度下是否变形、挤压、错位、裁切  
④ dark / light / nature 三主题下对比度、片/块可辨性、金色强调是否成立

**每类一句话取舍**

- **stack**：选 A——销有一枚独立画在框外的标记，pin=8 时也不会被金色段吞掉；B 的销条与块同宽同色，越重越找不到销。
- **plate**：选 A——三片/轴的片真的能数出来；B 的四片与轴同色，整根读成“带四个孔的斜杆”。A 另需处理与哑铃撞形。
- **dumbbell**：选 A——正视、头柄比例干净；B 的 -16° 加半透明副本把“一对”变成“一只带影子的哑铃”。
- **bw**：选 A——人+单杠直接读成引体；B 的两根立柱没有底座，读成笼子/深蹲架，图注里的“底座”也不存在。
- **special**：选 A——只有 A 真正画出了四形；B 只证明了三只壶铃能被装进格子，不能算该类别的完整方案。
- **barbell**：选 A——对称是杠铃的默认读法；B 的单侧装载读成锤子/狼牙棒。

## 二、缺陷清单（按严重度排序）

### 阻断级：会直接读错或读不出

1. **plate · B｜全宽、全主题，320 最糟**：四片与轴、机体共用 `--gear-metal`，片面只剩片孔和白描边可见；412 放大后仍是“一根细长斜杆末端有四颗小孔”，读成天线 / 注射器 / 高尔夫球杆。图注写“4 片、端帽可见”，但图形上找不到端帽——实现里也没有画（`plateHorn` 的端帽没有被 `plateBSVG` 调用）。这是 ②=2 的主因。

2. **stack · B｜pin 5/8、三主题**：销条是一根与块同宽的横向金条，正好压在金色段的下边界；pin=8 时整根落在金色片上，肉眼无法定位销位。亮底/咖啡底下未选中块几乎消失，只剩一串白色片孔，整张读成“打孔卡片 / 水位计 / 条码”。方向只能靠金色段长度，销本身不可读。

3. **dumbbell · A/B｜全宽，light/nature 最明显**：“成对”是同一只哑铃以 38% 不透明度向下偏移 9–10px 的重影；亮底/咖啡底看起来就是投影，暗底是“半透明复制品”。B 还整体旋转 -16°，重影与主体错位，变成“一只带脏影的哑铃”，不是两只。

4. **bw · A/B｜全宽、三主题**：加重态的“片”是一个 10×7 的金色小方块，挂在腰下，第一眼是腰带扣 / 护裆，不是挂片；辅助态是一条从左脚到右脚的虚线拱，读成跳绳 / 吊床，不是弹力带。B 图注写“两根立柱 + 顶梁 + 底座”，但图上没有底座，两根立柱悬空收在脚边，整张读成“笼子 / 深蹲架”，人像是在框里站着，不是吊着。

5. **stack · A/B｜light / nature，320/360 最糟**：未选中块 `#D7DEE8` / `#DCD3C2` 压在近白卡面上，对比约 1.2–1.4:1，边界只剩 0.8px 的淡描边。暗底正常；亮底/咖啡底下“整摞还剩多少块”看不出来——这恰好是让“销往下 = 更重”成立的那半个信息。④=2–3 的主因。

6. **plate · A｜全宽，40–80px 观感**：居中大机体 + 左右各三片，关掉标题就是“中间很粗的哑铃 / 杠铃”，与 dumbbell 类撞形；“空轴”两端的小金虚线环读成端帽螺栓 / 齿轮，不像“有标称重量但无整片”。这是全表里识别风险最高的一张。

7. **special · A｜全宽，320 的约 30px 尺寸**：四形里只有 kb/mb 勉强成立；rope 是两根波浪线交成的“Y / 树杈”，band 是空心椭圆“圈 / 呼啦圈”，kb 有提手弧但更像挂锁，mb 两条缝线像纽扣。四个 8px 英文小标签（kb/mb/rope/band）是唯一把它们分开的东西，而这些不是产品文案；去掉后 ① 会继续掉分。亮底/咖啡底下金色填充接近白色，只剩轮廓。

8. **special · B｜全宽、三主题**：这不是完整候选——只画了三只相同壶铃，无法证明它怎么表达药球 / 战绳 / 弹力带；圆角方格让它们更像三个“应用徽章 / 计数 chip”，而不是器械。作为“数量容器”成立，作为类别图形不成立。

9. **barbell · A/B｜全宽、三主题**：片序装反——最大片画在最外侧，最小片贴着中间；卡扣（金色竖条）画在片堆的内侧（靠中心一侧），与图注“卡扣在片外侧”相反。懂杠铃的人一眼看出“装反了”。B 又只画一侧，读成锤子 / 狼牙棒 / 牙刷。A 的对称仍是六类里最干净的一张。

10. **plate · 余量（B 方案）｜320–412、三主题**：末端金虚线环约 9px，读成“轴端的靶心 / 硬币 / 徽章”，不是“12kg 差一片”；而且边界态一栏用 A 画空轴、B 画余量，两个态不在同一方案里，无法直接采用。

### 系统级：跨类别、跨主题

11. **金色语义过载**：同一支 `--gold` 在五类里干了五件事——stack 的“已带起块”、bw 的“额外重量”、plate 的“缺一片（虚线）”、barbell 的“卡扣”、special 的“器械本体”。用户无法建立“金色 = 已选重量”的稳定规则，plate 的虚线金还和“已选”相反。亮底/咖啡底下 gold 变成深棕（约 `#8A5F0B` / `#7A5A16`），“金色”的品牌感已经没了，只剩语义冲突。

12. **warn 与 gold 太近**：dark 下 `--warn #F0C060` 与 `--gold #E0A83A` 同族，辅助弹力带（虚线黄）和 stack 的销 / barbell 的卡扣看起来是一个东西；light/nature 下两者也都是棕橙。“辅助”与“已选重量”的区分度不够。

13. **stack · A 的箭头是整张图里最弱的元素**：灰色、60% 不透明度、画在 frame 左侧外边；412 下高约 20px、笔画约 0.4px，320 下约 15px、约 0.25px。它单独一张图里是唯一的“方向”线索，却最看不见，可以被读成滚动条 / 吊绳 / 装饰线。方向感实际由金色段变长承担，而单图没有对照组，这个信息在 App 里不成立。②=3 而不是 4。

14. **stack · A 顶块两侧各加宽 2 单位**：读成“盖板 / 顶盖”，破坏了“所有片等宽”的模型；其余块等宽是对的，这一块的差异没有语义理由。B 没有这个问题。

15. **图注与实画不符，且会被原样抄进实现**：plate B“端帽+轴身可见”（未画）；bw B“底座”（未画）；barbell A“卡扣在片外侧”（实为内侧）。三处都是文案先于图形，比图形本身更容易骗过验收；落地前应让每条图注都能被截图证伪。

16. **stack 说明里的 `**销上方（含销片）的块才被带起**` 原样显示**：星号在所有 12 张截图里都在，抄进设计稿会一起抄进去。

### 宽度与排版级

17. **stack 三连排是被压小的，不是“适配”**：声明 96px 宽的三张图塞进约 128（320）/ 148（360）/ 163（390）/ 175（412）的卡片内宽，SVG 被 `max-width:100%` 压到约 30–48 CSS px。320 下块高约 1.4px、销约 0.8px、孔不到 1px、箭头约 0.25px；没有裁切、没有变形，但细节在物理上不见了。412 下卡片变宽，图形只到 48px，留白明显。③=3 的主因——这一项测到的是排版，不是图形。

18. **320 的 bw 行**：3×42 + 2×2 = 130，略超卡片内宽约 128，出现约 1% 压缩（没有可见裁切）；**special 行** 4×30 + 3×2 = 126，贴边，间隙只有 2px；390/412 完全不放大，卡片留白继续增大。

19. **评审页缺少“单图实际尺寸”视图**：现在每类都是三态/四形并排，所有图形的大小由“一排塞几个”决定。宽度项因此测的是评审页排版，不是产品里 40px 图标的样子；建议补 40 / 48px 单图两档，否则 ① 和 ② 的分数在落地尺寸下会失真。

20. **8px 英文 tag**：`pin 2/5/8`、`kb/mb/rope/band` 是评审页说明，不是产品文案；在“关标题”测试里不能算识别辅助。若产品里没有等价中文标签，special A 和 stack 的分数还要再降。

## 三、普通用户第一眼会误解的地方

- **plate A** → “中间很粗的哑铃”或“粗柄杠铃”。
- **plate B** → 天线 / 注射器 / 高尔夫球杆 / 钥匙；四片完全数不出来。
- **plate 余量** → 轴端别了一枚金色靶心 / 硬币。
- **stack B** → 打孔卡片 / 水位计 / 条码；中间的虚线是刻度，不是销。
- **stack A** → 左侧竖线像滚动条，金色横杆像摇柄 / 拉杆，而不是插销。
- **dumbbell A/B** → 一只哑铃带投影 / 重影照片，不是“一对”。
- **bw A** → 腰部金色块 = 腰带扣 / 护裆；虚线拱 = 跳绳 / 吊床。
- **bw B** → 笼子 / 深蹲架；人在里面“站着”，不是吊着。
- **special A** → 挂锁（kb）、纽扣 / 棒球（mb）、树杈 / 字母 Y（rope）、呼啦圈 / 圈（band）。
- **special B** → 三个应用徽章，不是器械数量。
- **barbell B** → 锤子 / 狼牙棒 / 牙刷。
- **barbell A**（懂杠铃的人）→ “片装反了，卡扣也装在里面”。

## 四、总评

A 普遍优于 B，但六类里只有 stack A、dumbbell A、barbell A 能在关掉标题后自解释；其余方案都在靠图注活着，尤其 plate B、dumbbell 的“成对”、bw 的加重/辅助、special 的绳/带四处必须先重画，不能带进 v0.70。
