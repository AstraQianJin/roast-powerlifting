## 1. 调研：真机结构与必须存在的要素

### 1.1 插片（selectorized weight stack）

真机：一摞等宽配重块装在立柱/护罩内，顶部由缆绳（或连杆）牵动；插销从块侧面水平插入。**只有销所在块及其上方的块被带起**，下方块留在底座上。因此“销往下 = 带起更多块 = 更重”是机械事实，不是约定。

来源依据：
- Echo Strength Depot 对 selectorized 机器的说明：“only the weight plates located above that pin are engaged”。
- Nautilus 2ST 手册：“insert it into a hole lower down the stack to engage more weight plates”。

必须存在的视觉要素：
1. ≥ 8 个等宽、等厚的块，块间有缝，能数。
2. 一整摞的**上下边界**（顶块与底块都要在画面里）。
3. 销：一根**明显比块窄**的水平杆 + 端头，插在“已啮合段的最下沿”。
4. 已啮合段：从顶块到销所在块，整段实心；未啮合段弱化为空块。
5. 缆绳/滑轮（仅 cable 变体）：顶部一个滑轮 + 一小段缆绳。

容易画错：
- 画成“一根竖条 + 填充高度”（现在的 `geg-ladder` + `geg-fill`）：读成进度条/水位计，不是配重堆。
- 把销画在与块同宽的横条上：整条落在金色段里时找不到销（评审第 2 条）。
- **填充方向反了**：现在 `k<=n` 让“低索引=轻”的块落在下方并被点亮，销在底部时反而只亮一块，与“销往下更重”完全相反。
- 销位比例用固定分母（`pin/12`）而不是当前窗口 `lo..hi`，档位数一变就错位。

### 1.2 挂片（plate-loaded，含 Hammer Strength）

真机：机体（座椅/靠垫/力臂）两侧伸出**水平的圆形挂片轴（weight horn）**，杠铃片套在轴上；为稳定重心，通常靠近机体一侧先装大片、向外递减。Hammer Strength 机型常见每侧 1–2 根轴，整机 4–8 根（含存储轴）。

来源依据：Hammer Strength / Life Fitness 产品页给出的 “Number of Weight Horns: 6/8”“4–45 lb plates/horn”“long, angled weight horns”。

必须存在的视觉要素：
1. 一个可辨认的**机体**（不是一根竖柱）。
2. 每根轴是**水平/略斜的圆柱**，有端帽。
3. 片是**圆盘**（正视时画成椭圆截面），片径沿轴向外递减。
4. 片数可数（每轴一叠，片间有缝）。
5. **空轴 = 轴 + 端帽 + 轴身**，不是空白，更不是文字。
6. 余量（凑不出整片）：在最外侧画一圈**虚线圆盘轮廓**（“缺一片”），不加文字。

容易画错：
- 画成“一排竖柱 + 片条”（现在 `geg-post` + `.geg-stack`）：读成栅栏。
- 片与轴同色同形：整根读成“带孔的斜杆/天线”（评审第 1 条）。
- 机体太粗、两侧对称片 → 与哑铃撞形（评审第 6 条）；机体要有底座、座椅凹槽、比例更扁。
- 用文字“每位无片”兜底（现在 `renderGearPlateBar` 的 `pv-empty`）。

### 1.3 其余类别

- **哑铃**：一根明显细于头片的柄，两端各一叠头片；成对是两只独立器械。易错：用透明度/投影画第二只。
- **自重/辅助**：单杠或引体架；加重 = 腰带挂片；辅助 = 弹力带（从底座到膝/脚）。易错：画成“横杠穿片”（杠铃），或引体架没有底座。
- **特殊**：壶铃（球体 + 提手弧）、药球（球体 + 缝线）、战绳（两股粗绳）、弹力带（闭环）。易错：靠文字 tag 区分；金色铺满本体导致主题切换后只剩轮廓。
- **杠铃**：横杠 + 两端套管 + 片 + 卡扣。易错：大片装在最外侧、卡扣画在片堆内侧。

## 3. 逐类设计规格

> 以下 viewBox 与数值即候选页实现值；落地时保持比例，只按容器缩放。所有 `data-*` 是给断言用的稳定钩子，不是展示文案。

### 3.1 stack · 插片

#### 3.1.1 方向语义（最重要的一条）

```
索引 i：0 = 最上一片 = 最轻 … n-1 = 最下一片 = 最重
销位 pin：销插在第 pin 片的下沿
被带起（engaged）：i ∈ [0, pin]，共 pin+1 片，画在图的上段
未啮合（idle）：i ∈ (pin, n-1]，画在图的下段
重量：levels[pin]
```

因此：`pin` 增大 ⇒ engaged 段向下延长 ⇒ 实心块数增加 ⇒ 重量递增。图中不需要文字说明方向。

#### 3.1.2 几何（viewBox 132 × 104）

| 元素 | 参数 |
|---|---|
| 滑轮 | 圆心 (66,10)，r=4.5，stroke=`--dim` 1.4；缆绳 (66,14.5)→(66,20) |
| 外框 | x=40,y=20,w=52,h=80,rx=5，fill=`--inset`，stroke=`--edge` 1.2 |
| 块 | x=44,w=44,h=6, gap=1，首块 y=24；n=10 时末块底 y=93 |
| 已啮合块 | `--gold`，无描边（相邻块靠 1px 缝分隔） |
| 未啮合块 | `--gear-idle`，stroke=`--line2` 0.8 |
| 销（A 侧插） | 杆 x=88→103，y=pin 下沿 −1.6，h=3.2；端头圆 (105, y) r=4；fill=`--gold`，stroke=`--bg` 1.4 |
| 销（B 正面） | 横条 x=47,w=38,h=4；正面钮椭圆 rx3.4/ry2.6 |
| 方向标尺（A） | 竖线 (27,26)→(27,86) + 箭头 21,82→27,94→33,82；stroke=`--dim` 1.8，opacity .75 |
| 窗口 | 编辑器只渲染 `[lo,hi] = [pin-5, pin+5]` 与档位表交集，避免 60 档全画 |

#### 3.1.3 方案

- **A（采用）**：侧插销 + 货架式外框 + 左侧向下标尺。销在框外仍可见，是方向的第二线索。
- **B（备选，不进 v0.70）**：正面插槽 + 块心留孔。片孔能证明“销从正面插入”，但销条与块同宽时易被金色吞掉，评审②=2。

#### 3.1.4 必须删掉的旧画法

| 现状（`template.html`） | 问题 | 替代 |
|---|---|---|
| `gearGlyph` 的 `<i class="geg-ladder"><i class="geg-fill" style="height:pct%">` | 一根贯穿竖条 = 用户说的“左边竖杠”；`pct=pin/12` 分母写死 | 等宽块列（§3.1.2），比例按 `lo..hi` |
| `renderGearStackBar` 的 `for(k=hi;k>=lo;k--)` + `k<=n?'on'` | 索引方向反：销在底部时只亮 1 块 | 索引升序自上而下；engaged=`i<=pin` |
| `geg-pin` 的 `bottom:pct%` | 销贴在填充段顶部，方向读反 | 销贴 engaged 段**下沿** |
| 档位条内的 `#i base+pin×inc=kg` 文本 | 旧模型已退役，文本复活退役字段 | 删除；读数留在配置摘要 |

### 3.2 plate · 挂片

#### 3.2.1 结构

```
机体（中央，带底座与座椅凹槽）
  ├─ 左轴 ── 片（靠机体大 → 向外小） ── 端帽
  └─ 右轴 ── 片（同规则） ── 端帽
```

- `posts` = 轴数（1–4）。布局：1 → 右轴；2 → 左右各一；3 → 左一右二（上下错位）；4 → 每侧两根（y=38 / 64）。
- 每轴片数来自 `recipe.plates`；`perPost` 是每轴净重。
- 空轴：只画轴 + 端帽 + 端头小圆，**不写“每位无片”**。
- 余量（`recipe.remainder>0` 且无整片）：最外侧加一圈与真片同径的虚线圆盘轮廓。

#### 3.2.2 几何（viewBox 150 × 100）

| 元素 | 参数 |
|---|---|
| 机体 | x=62,y=18,w=26,h=72,rx=7；底座 x=38,y=92,w=74,h=3,rx=1.5；座椅凹槽 x=66,y=54,w=18,h=7,rx=3.5 |
| 轴 | 长 47（62→15 / 88→135），厚 5，rx2.5，`--gear-metal` |
| 端帽 | 5×12，rx2，位于轴外端 |
| 片 | `ellipse` rx=4.2（厚度），ry=片半径；片径 16 / 12 / 9（靠机体→外）；间距 6 |
| 片孔 | `ellipse` rx=1.7，ry=max(2, r*0.45)，`--bg` |
| 空轴幽灵 | 虚线 `ellipse` rx=4.2，ry=16（与最大片同径），`--dim` |
| 余量幽灵 | 虚线 `ellipse` rx=4.2，ry=max(6, r_last*0.7)，画在端帽外侧 7 |

#### 3.2.3 方案

- **A（采用）**：正视双侧轴 + 机体底座。片数可数；低宽度下机体与片分离清楚。
- **B（备选）**：单侧特写斜轴。片径递减最直观，但片与轴同色系时整根像“带孔斜杆”。

## 6. 验收判据（都能写成断言）

### 6.1 结构类

1. **插片片位存在**：`[data-gz="stack"] [data-idx]` 数量 ≥ 8（编辑器窗口内 ≥ min(11, N)）。
2. **销位方向**：`engaged = [data-idx][data-engaged="1"]`，其数量 === `pin+1`；且 `max(engaged.idx) === pin`。
3. **方向递增**：`pin` 从 2 增到 8 时，`engaged.length` 从 3 增到 9（同一档位表，断言单调）。
4. **销贴下沿**：`pinEl.getBoundingClientRect().top + pinEl.height` 与 `lastEngaged.bottom` 差 ≤ 2px。
5. **无竖杠**：`gearGlyph` 输出不含 `.geg-ladder` / `.geg-fill`；输出文本 `trim()===''`。
6. **挂片片数**：每根 `[data-gz="horn"]` 内 `[data-gz="disc"]` 数量 === `recipe.plates.length`；`data-r` 沿轴向单调递减。
7. **空轴可画**：`plates.length===0` 时 `[data-ghost]` 数量 ≥ 1，且容器 `textContent.trim()===''`（不得出现“每位无片”）。
8. **哑铃成对**：`sides=2` 时 `[data-side]` 数量 === 2，且两组 `opacity===1`（不得靠透明度伪装）。
9. **自重三态**：`[data-mode]` ∈ `{bw,plus,assist}`；`plus` 有 1 个 `[data-gz="extplate"]`，`assist` 有 1 条 `[data-gz="band"]`；`assist` 的路径终点落在架体基线（±3px）。
10. **杠铃片序**：`[data-gz="plate"]` 的 `data-r` 按“靠套管→外侧”单调递减；卡扣 `data-gz="collar"` 的 |x−中心| 大于最外片。

### 6.2 主题类

11. `--gear-idle` / `--gear-metal` / `--gear-cut` 在 `dark` / `light` / `nature` 三块令牌里各声明一次；`grep` 无第二份色值。
12. gear 相关 CSS/JS 无十六进制色值（S33 口径）；`getComputedStyle` 取到的 `background-color` 必须来自令牌。
13. 亮底主题下：未啮合块与卡片底对比 ≥ 3:1（可用 CIEDE/对比度脚本算，不靠肉眼）。
14. 三个主题下 `--gold` 只在 §4.3 允许的元素上出现；`[data-gz="ghost"]`、`[data-gz="collar"]`、`[data-tag]` 的描边/填充不得解析为 gold。

### 6.3 宽度/尺寸类

15. 320 / 360 / 390 / 412：`documentElement.scrollWidth === innerWidth`，且 gear 区域无 `scrollWidth > clientWidth` 的子元素（候选页 12 次实测 `over:[]`）。
16. 首页 strip 图形 `getBoundingClientRect()` 宽 ≤ 26、高 ≤ 34；编辑器配重图高 ≤ 96。
17. **40px 档**：plate 图形允许仅作 48px 档使用（评审 §2.4 结论）；若产品必须在 40px 显示 plate，则追加“机体底座占宽 ≥ 20%”的判据，否则退回 48px。

### 6.4 能红（反向验证）

- 把 `engaged` 条件从 `i<=pin` 改回 `i>=pin`：断言 2/3 必红（销向下反而片数减少）。
- 把销的 `y` 改成 engaged 段顶端：断言 4 必红。
- 把 `plate` 分支改回 `geg-post` + 矩形片：断言 5/6 必红。
- 在 `plates.length===0` 时塞回 `每位无片` 文本：断言 7 必红。
- 把哑铃第二只用 `opacity:.38`：断言 8 必红。
- 把 `--gear-idle` 改回 `#D7DEE8`（light）：断言 13 必红。

每条新断言先跑旧实现确认红，再在新实现上跑绿（AGENTS §2.6）。
