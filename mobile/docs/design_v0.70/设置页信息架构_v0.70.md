# 设置独立页 · 信息架构与文案重构方案（v0.70）

> 性质：**只读设计**。本文件只出方案，不改 `template.html`、不跑生成链、不跑门禁。
> 引用基线：`mobile/tools/template.html`（读取时 mtime `2026-11-07 10:27:20`，`git status` 显示该文件处于未提交修改态）。
> 行号会随该文件继续被编辑而漂移，因此**每条引用同时给出元素 id 与函数名**；定位时以 id/函数名为准，行号只作当次快照。

---

## 0 · 结论先行

用户原话要解决的是两件事，本方案把两件事分开处理：

1. **导航问题**：现在所有设置子页都是同一个模态层里的独立 `.sheet`，点进去时先 `closeSheet('setSheet')`，返回键又直接 `closeAllSheets()`，所以从任何子页退出都落回首页。→ 设置改成**独立页面 + 子页返回栈**，返回逐级回退，最外层才回首页。
2. **气质问题**：现在的 17 行里有大量"引擎 / 台账 / 契约 / 原子写 / 六表 / JSONL / 迁移 / v7 / 阈值回测 / 推断"这类工程词，还有大段给开发者看的口径注释。→ 主页只留**消费者能一眼看懂的名词 + 一句人话**，工程内容统一下沉到「高级 · 帮助」。

同时修掉 4 个结构缺陷（详见 §1.9）：两个入口进同一个页面、监控开关没有"进入"路径、关于页品牌名与项目规则不一致、中英混排的分组标题。

## 1 · 现状盘点

### 1.1 为什么"总是返回首页"（机制证据）

| 事实 | 位置 | 说明 |
|---|---|---|
| 设置本体是一个下弹模态 | `#setSheet`，`template.html` L2138 | `class="sheet down"`，不是页面容器 |
| 入口只有一个 | `openSettings()` L11632 | `renderSettings(); showSheet('setSheet')`，由顶栏 logo 触发（L1721） |
| 每个子页跳转前先关设置 | 全仓共 **18 处** `closeSheet('setSheet')` | 设置主页 12 个跳转行 + 科学库 3 + 归档 1 + `openLibrary()` L11092 + ✕ 按钮 L2143 |
| 子页打开 = 叠一个新 sheet | `showSheet()` L11406 / `closeSheet()` L11411 | 只做 `classList.add/remove('on')` + `zIndex`，**没有栈** |
| 返回键 = 全关 | `window.__handleBack` L14425 | 只要有 `.sheet.on`，就 `closeAllSheets()`（L14429 附近），所以一层返回直接清空所有层 → 首页 |
| 设置页自身也没有返回语义 | `#setSheet` 的 ✕ L2143 | 只有"关闭"，没有"上一级" |

**结论**：这不是某一个子页的 bug，是容器模型决定的。只要设置还是"叠层"，就无法实现"子页 → 设置页"；必须引入页面 + 栈。

### 1.9 结构缺陷（改版必须一起修）

1. **两个门，一间屋**：`运动员档案`（L2150）和 `运动员水平`（L2166）分别调 `openProfile('bio')` / `openProfile('1rm')`，但 `openProfile()`（L9050）**没有参数**，两次进的是同一张完整 profSheet。消费者视角是"两个入口点进去看到同一页"。→ 合并为一张「我的档案」，内部用 tab 分「身体 / 力量 / 目标」。
2. **开关没有进入路径**：`每日状态监控` 只有一个开关（L2154），开启后去哪里记录？只能回首页点 STATUS 舱。→ 开关右侧在有数据/开启时补一个 `›`，直达每日记录页。
3. **品牌名不一致**：主页行 `#setAboutT` L2234 写"关于 Roast PowerLifting 训练体系"，子页静态 `#aboutTitle` L2092 写"关于 ExDark Pro"，i18n L6050/L6210 又把两者统一成"Roast PowerLifting"。项目规则要求界面品牌为 `ExDark Pro`。→ 三处统一为"关于 ExDark Pro"。
4. **中英混排标题**：六个分组标题在中文模式下都带 `· ENGLISH` 尾巴（L6058–L6063）。→ 按语言单语输出。
5. **名叫"只读"的页面会写数据**：`openAdviceSheet()`（L10545）在打开时直接调用 `advAutoRun()`，当档位为"自动应用"时会当场批量写回下周重量。主页文案却写"智能训练引擎（只读）"。消费者看不到"打开设置就改了计划"这件事。→ 档位提到设置页显式选择，并在首次切换到"自动应用"时弹一次确认。

## 2 · 目标分组结构

### 2.1 分组原则

- 按**用户此刻要解决的事**分组，不按代码模块分组。
- 高频在上：档案 → 训练 → 健身房 → 工具；低频在下：外观 → 数据 → 关于。
- 工程/排障单独一个**默认折叠**的「高级」卡，且放在最底部。
- 每组 3–6 行；超过 6 行就再拆子页，不在主页堆砌。

### 4.4 子页与返回路径（核心）

- `#setPage`：独立全屏页面容器，内部滚动；不再用 `.sheet`。

- 编辑写入策略沿用现状：开关/选择器即时保存；表单页（档案、训练计划、恢复评估）保留底部"保存"。

  1. 若 `settingsStack` 非空 → 弹出一层，`return true`；

## 5 · 小工具区

### 5.1 位置与排序

放在「器械与场地」之后、「外观与提示」之前。理由：工具是"训练中/训练前"用，属于高频实用区；外观是"设置完就不动"的低频区。

| 序 | 工具 | 理由 |
|---|---|---|
| 1 | 配重计算器 | 训练中最高频：这杆到底挂多少片 |
| 2 | RM 计算器 | 次高频：这个重量能做几次 / 这个次数对应多少 1RM |
| 3 | 系数计算器 | 低频：GL/DOTS/Wilks，评估与比赛报名时用 |
| 4 | 恢复器械默认 | 极低频、破坏性；放最后并用红字，避免误触 |

### 5.2 每个工具的字段与边界

**① 配重计算器 `Plate Calculator`**

- 输入：器械类型（沿用 `GEAR_SCHEMA.kinds` 六类）、参数、目标重量。
- 输出：总重 + 单侧配片图（复用现有 `paintPlate` 图形，不新造视觉）。
- 已有实现：`renderLoadCalc()` L8821、`paintLoadCalc()` L8851、`readLoadCalc()` L8833、`fillLoadFromCalc()` L8862、`lcPickType()` L8793 附近。
- 边界：工具页默认**不写任何状态**；"填入当前动作"只在从编辑器进入时出现，独立入口不显示该按钮。
- 迁移方式：把 `.lcalc` 的渲染函数抽成可挂两个容器（编辑器内 + 工具页），参数不落盘（`lcOpen` 之类视图偏好可继续存 prefs）。

**② RM 计算器 `Rep Max Calculator`**（新建）

- 模式 A（由重量推极限）：重量 + 次数 + RPE（可选）→ 估算 1RM。
- 模式 B（由极限推重量）：1RM + 目标次数 → 各百分比对应重量表（如 100/95/90/85/80/75/70%）。
- 输出必须标注"**估算值**"，并明确"不会写入档案"。
- 公式必须与项目现有 e1RM 口径一致（`figMethodsText()` L9852 的 `load × (1 + (min(reps,12)+RIR)/30)`，RIR = 10 − RPE），避免出现两套算法。
- 不新增契约、不写 `state`、不参与导出。

**③ 系数计算器 `Strength Score`**（由只读展示升级）

- 输入：体重、性别、装备、深蹲/卧推/硬拉（可临时改，不落档案）。
- 输出：IPF GL、DOTS、Wilks 2、段位。
- 已有算法：`calcIpfGl()` L4404、`calcDots()` L4412、`calcWilks2()` L4420、`calcGlRank()` L4436。
- 边界：顶部注明"试算不会改动你的档案"；提供"用我的档案数据"按钮回填。

**④ 恢复器械默认 `Reset Gym Defaults`**（新建，危险动作）

- 重置范围必须**明确列出**：
  - 每个动作的器械类型修正（`state.gearDefaults`，`setGearGuess()` L5606）；
  - 配片库存（`venueInv().plates` 相关）、哑铃库存（`venueInv().dumbbells`，`setDumbUnlimited()` L8441）；
  - 杠铃杆重（`setBarKg()` L4840 附近）、赛扣（`toggleCollars()` L4850 附近）。
- **不得触碰**：训练计划重量、`state.weeks` 里的载荷、e1RM 账本、归档、CSV。
- 交互：红色行 → 点击弹确认 → 二次确认（沿用 `undoMigrate` 那类"再点一次确认"模式）。确认文案要写清"只改器械设置，不改训练计划"。
- 理由：这是唯一会让用户"以为数据没了"的动作，必须把边界写进 UI，而不是写在文档里。

### 5.3 工具与现有页面去重

- 编辑器内的配重计算器**保留**（临场就地算），但文案统一为"配重计算器"，参数默认值共享。
- 档案页的 GL/DOTS/Wilks 展示**保留**（它是"我的水平"的一部分），系数计算器是它的"沙盒版"。
- 图表 hub 里的「阈值回测校准」**移入高级**，不再和用户报告混排。
